# Moss & Light

Moss & Light will be an image-search app for finding visual inspiration from around the world. The forest-green and warm-paper palette gives it the feeling of a calm field guide rather than a conventional search page. I chose a row of four topical chips to make it easy to imagine a search starting point. I also kept the empty results area spacious and paired it with a gentle prompt so the page explains what to do before the first search.
