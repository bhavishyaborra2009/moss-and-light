# Moss & Light

Moss & Light is an image-search app for finding visual inspiration from around the world. The forest-green and warm-paper palette gives it the feeling of a calm field guide rather than a conventional search page. Four topical chips provide quick starting points, and the empty results area explains how to begin.

Searches use the Wikimedia Commons API, so no API key is required. Submit a topic with the Search button or Enter, or choose one of the suggested searches. Each result links to its full image, and the heading reports how many matches were found.
